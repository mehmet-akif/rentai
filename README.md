# RentAI

AI-powered rental intelligence platform built with React, Node.js, MongoDB Atlas, Docker, and cloud-ready deployment architecture.

## Features

- AI rental advisor
- Smart rental matching
- Interactive maps
- Rental analytics dashboard
- Price intelligence
- Saved listings
- Property detail pages
- Demo listing submission
- Dockerized frontend/backend

## Tech Stack

Frontend:
- React
- Vite
- Leaflet
- Recharts

Backend:
- Node.js
- Express.js
- MongoDB Atlas
- OpenAI API

DevOps & Cloud:
- Docker
- Docker Compose
- Azure-ready architecture
